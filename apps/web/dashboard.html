Connect

Already using OpenAI? Change the base URL and use your Forsig key.

One-line migration baseURL: "https://gateway.forsig.com/v1"
JavaScript SDK 
import OpenAI from "openai";
import { forsigHeaders } from "@forsig/sdk";

const client = new OpenAI({
  apiKey: process.env.FORSIG_API_KEY,
  baseURL: "https://gateway.forsig.com/v1",
});

await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "Help this customer" }],
}, {
  headers: forsigHeaders({ externalUserId: "cust_123" }),
});
Python SDK 
from openai import OpenAI
from forsig import forsig_headers

client = OpenAI(
    api_key=os.environ["FORSIG_API_KEY"],
    base_url="https://gateway.forsig.com/v1",
)

client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Help this customer"}],
    extra_headers=forsig_headers(external_user_id="cust_123"),
)
