How it works

One review checkpoint. Five possible decisions.

01

Agent pauses

Your agent reaches a risky, uncertain, or customer-impacting action.

02

Human reviews

Forsig shows the proposed action, context, and risk in a secure review page.

03

Workflow resumes

The agent receives approve, reject, edit, instruct, or takeover as structured data.

Where it fits

Use Forsig before actions that affect customers, money, data, or reputation.

Refunds Customer emails CRM updates Tool failures Policy exceptions Human takeover

Developer flow

Call Forsig only when your agent needs human judgment.

Illustrative SDK example
const decision = await forsig.intervene({
  agent: "refund-agent",
  runId: "run_123",
  risk: "refund_over_limit",
  proposedAction: "Issue $500 refund",
  waitForDecision: true
});

if (decision.status === "edited_approved") {
  await continueWorkflow(decision.editedAction);
}

What is Forsig?

Forsig is a human intervention API for AI agents. It lets agents pause before risky actions and return a structured human decision.

Does Forsig replace my agent framework?

No. Forsig works beside your current agent stack. Your app still executes the final action.

What can a human do?

Approve, reject, edit and approve, instruct the agent, or take over the task.

Is it live?

Forsig is in private beta. The website shows the intended product direction and waitlist flow.
