The missing layer

Most agent failures do not need another dashboard. They need a human decision at the exact moment of risk.

Agents are becoming operators. They draft emails, change records, run tools, and make customer-facing choices. Forsig gives them a simple escalation path before a mistake becomes production reality.

How it works

Give agents a safe way to ask for help.

Forsig sits beside your existing agent stack. Your agent calls Forsig only when it needs approval, escalation, or human judgment.

01

Pause

The agent reaches a risky action: refund, external message, record update, billing action, deployment, or sensitive workflow.

02

Ask

The agent sends Forsig the task, proposed action, risk type, run ID, and context needed for review.

03

Decide

A human approves, rejects, or edits the instruction from the web inbox, with Slack and email workflows planned.

04

Resume

The agent receives the decision and continues safely with a complete audit trail.

Developer-friendly

Call Forsig when your agent needs approval.

The private beta API is focused on escalation requests, reviewer decisions, and agent resume workflows. SDK examples are illustrative while the beta API is finalized.

JavaScript example
const decision = await forsig.escalate({
  agent: "refund-agent",
  runId: "run_123",
  task: "Approve refund for customer #123",
  risk: "refund_over_limit",
  proposedAction: "Issue $500 refund",
  context: {
    customerTier: "VIP",
    orderValue: 1200,
    reason: "Product failed twice"
  }
});

if (decision.status === "approved") {
  await issueRefund(decision.instruction);
}

What is Forsig?

Forsig is a human approval layer for autonomous AI agents. It lets agents pause before risky actions, ask a human for a decision, and resume with an auditable response.

Is Forsig an AI gateway?

No. Forsig is not primarily an AI gateway. Agents call Forsig only when they need approval, escalation, or human judgment.

What channels does Forsig support?

The private beta starts with a web approval inbox and planned Slack/email workflows. WhatsApp, Discord, Microsoft Teams, and other channels may be added based on user demand.

Who is Forsig for?

Teams building AI agents, workflow automations, AI support systems, internal operations agents, and human-supervised AI workflows.

What actions should be escalated?

Refunds, external messages, account changes, billing actions, customer-impacting decisions, sensitive data workflows, high-cost operations, and any action where human judgment is required.

Does Forsig replace my agent framework?

No. Forsig works alongside your existing agent stack. Your agent calls the Forsig API when it needs human approval.

Is Forsig production-ready?

Forsig is currently in private beta. Early users should expect setup help, fast iteration, and active feedback loops.
