The Forsig safety loop

Your agent proposes. Forsig halts execution. You decide.

01

Agent proposes an external action

Refund, email, deployment, database change, paid tool call, or any action where mistakes matter.

02

Forsig creates a checkpoint

The workflow waits while a reviewer sees the proposed action, risk reason, and minimal context.

03

The agent receives a decision

Approve, edit, or reject. Forsig returns a structured response your workflow can trust.

agent.ts
const decision = await forsig.escalations.create({
  action: "stripe.refund",
  risk: "refund_over_limit",
  context: { amount: 500, customer: "VIP" }
});
